# chatbot-richard

Chatbot de ventas genérico para negocios pequeños (tienda, peluquería, gimnasio). Atiende
WhatsApp, Facebook e Instagram, toma pedidos completos (descuenta stock o agenda en Google
Calendar) y no inventa precios, stock ni horarios: cada cifra sale de la capa SAS.
Corre en Docker, un stack por cliente, sobre una Oracle VM Always Free.
