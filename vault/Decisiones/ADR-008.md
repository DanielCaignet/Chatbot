# ADR-008 — Antigravity: prueba de descarte

> Inmutable. Si la decision cambia se escribe un ADR nuevo con `supersedes: [ADR-008]`.

## Contexto
El usuario quiere probar Antigravity como agente para comprobar si efectivamente no sirve. Es un IDE con suscripción personal, sin API de servidor conocida.

## Decision
Prueba de descarte en el spike con seis criterios obligatorios: invocación programática sin GUI, ≥3 conversaciones concurrentes aisladas, p95 <15 s, uso de la MCP del SAS, 24/7 en Linux ARM o accesible desde la VM, y términos que permitan atender a terceros. Falla uno → descartado. Resultado como tabla pasa/falla en el vault.

## Alternativas descartadas
- Descartarlo sin probar — no: el usuario pide evidencia.

## Consecuencias
- Si pasa los seis, se compara con Hermes sobre el mismo banco de evals.
