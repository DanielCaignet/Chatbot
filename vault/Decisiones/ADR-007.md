# ADR-007 — Modelo local descartado para el agente

> Inmutable. Si la decision cambia se escribe un ADR nuevo con `supersedes: [ADR-007]`.

## Contexto
El usuario propuso un modelo local para ahorrar costo. La VM no tiene GPU y tiene 2 OCPU según los docs actuales.

## Decision
No usar LLM local como agente. A lo más, embeddings locales para búsqueda en el catálogo.

## Alternativas descartadas
- Modelo 4B–8B Q4 en la A1 — descartado: un 7B genera ~8–12 tok/s con 4 OCPU [EXT:LLM local en Ampere A1], insuficiente para ~2.000 llamadas al día con prompts de 3–4k tokens.

## Consecuencias
- El costo de modelo pasa a BYOK ([[ADR-004]]).
- Libera la VM para los stacks de clientes.
