# Canal

## Definicion
Abstracción de mensajería (WhatsApp vía Evolution/Baileys, WhatsApp Cloud API, Messenger, Instagram) que entrega mensajes normalizados al gateway y envía respuestas.

## Por que importa en este proyecto
Permite migrar de Baileys a la API oficial sin tocar el agente.
