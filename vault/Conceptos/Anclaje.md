# Anclaje

## Definicion
Regla por la que todo identificador, umbral o texto que el agente pasa a una herramienta debe venir del mensaje del cliente o de un resultado previo de una herramienta.

## Por que importa en este proyecto
Impide que el modelo invente un SKU o una fecha y la consulte como si existiera [INT:D:/Dataseed/CristalChile-Maqueta/src/ui_plan.py].
