# Antigravity terminos

## TL;DR
Términos adicionales de servicio de Google Antigravity, leídos el 2026-10-02. Base del criterio 6 de [[ADR-008]].

## Que aporta a este proyecto
Evidencia contractual para decidir si Antigravity puede atender a terceros.

## Datos duros
- Cláusula 6: "Using third party software, tools, or services to access the Service (e.g. using OpenClaw with Antigravity OAuth) is a breach of this Agreement." Puede causar suspensión o terminación de las cuentas de Antigravity y Gemini CLI [Seguro, texto del contrato].
- Cláusula 4: el usuario es el único responsable de lo que haga un agente de IA y de supervisarlo en producción [Seguro].
- Cláusula 3: Google registra y almacena las interacciones, y las usa para mejorar sus productos salvo que se cambie la preferencia [Seguro]. Choca con la Constitución IV si hubiera datos reales.
- Los términos no se aplican a quien accede vía Gemini Enterprise / Workspace con otros términos [Seguro].
- Respuestas de comunidad en el foro de Google dicen que `agy -p` (sin pantalla) está soportado para scripts propios; **no es el contrato** [Probable]. Ejemplo: https://discuss.ai.google.dev/t/is-invoking-the-official-agy-cli-in-headless-mode-from-a-local-ai-coding-assistant-allowed-on-an-individual-google-ai-account/185992
- El contrato no contiene ninguna cláusula que autorice atender a clientes finales con una cuenta personal [Probable: ausencia de cláusula, no verificada con consulta legal].
