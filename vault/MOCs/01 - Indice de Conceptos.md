# Indice de Conceptos — chatbot-richard

> Cada termino del dominio tiene **una** ficha dueña. Lo demas enlaza.

## Datos y verdad
- [[Capa SAS]]: arnés de datos que impide inventar cifras
- [[Catalogo semantico]]: semantic.yaml aprobado por el admin
- [[Ledger del turno]]: respaldo contra el que se verifica cada cifra
- [[Anclaje]]: los identificadores vienen del cliente o de una herramienta
- [[Accion de pedido]]: preparar → confirmar, cambia solo el destino

## Negocio y operación
- [[Tenant]]: un negocio cliente, stack aislado
- [[Rubro]]: plantilla por tipo de negocio
- [[Takeover]]: el admin toma la conversación
- [[Canal]]: abstracción de mensajería
